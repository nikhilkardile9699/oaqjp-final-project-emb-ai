# # Emotion Detection Application

## Project Description

This project is an Emotion Detection Application developed using
IBM Watson NLP and Flask.

The application analyzes a given text and identifies emotions such as:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion from the detected emotions.

## Technologies Used

- Python
- IBM Watson NLP
- Flask
- Unit Testing
- Static Code Analysis
